# Lineup seed credit

Source: https://github.com/ReneRebsdorf/CS2-annotations/blob/main/local/de_mirage/de_mirage.txt
Retrieved 2026-11-20. Original node IDs retained. Names and instructions simplified.
Coordinates and aim angles retained. All throws await verification in CS2.
The named kellran/annotations fork was also checked; neither source supplies ten CT smokes.
The seed contains 12 T smokes and one CT smoke. Five additional CT proposals are app-authored (source: own), all checked=false.
Their coordinates use the Mirage overview and existing seed landmarks. Aim angles use an ideal ballistic estimate: speed 675, gravity 320, eye height 64, low arc, with the CS throw pitch adjustment. This does not account for walls, bounces, release offset or actual map collision geometry. These are practice candidates, not verified throws.
Landmark wording for seed instructions was expanded by the app and needs visual checking.
Round 2 replaces the unreachable Bench target with a nearby B apartments exit candidate
at (-1880, 680, -135), 310.64 units horizontally from the stand point. The same model
gives pitch 9.847065 and yaw 56.821488. A regression test checks its ideal flight
height; this is not a collision or landmark verification in the real map.
No game pictures are distributed.
