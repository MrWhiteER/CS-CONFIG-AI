Connection

        

          CS2 timestamps the exact moment you click, so a packet that never arrives is a
          shot the server never saw — however clearly it landed on your screen. That is
          what “no reg” usually is. This measures loss and jitter to your own router and
          out to the internet separately, so you can tell which side the trouble is on.
          It takes five seconds and changes nothing.

Setups

        

          Practice, a match and recording want different things. Save what you have
          chosen under a name and switch between them. A setup only decides what the
          next Apply will write — switching changes nothing in the game by itself,
          and never touches which folder you are working on.

Sound devices

        

          With more than one headset, or a mixer, Windows moves the default on its own
          — a driver update, a device waking, a USB interface re-enumerating — and
          you find out in the first round. Choose them here and the app puts them back
          whenever that happens.

Start a config

        

          This account has no config of its own yet, so there is nothing to read and nowhere
          to write a key bind to. Creating one lays out the usual folders and an
          autoexec.vcfg that execs them, ready for the Keyboard and Scripts tabs.
          Nothing that already exists is ever overwritten.
        

        

        

          
        

        

      


      

        
Carry this setup

        

          Everything this account has chosen, plus a copy of its configuration folder,
          in one file. Take it to another PC, or keep it as something to come back to.
          Nothing identifying goes in — no account, no paths from this machine —
          so it can be handed to somebody else as it is.

          Scan a folder of .cfg / .vcfg files to see how they load, what
          depends on what, and where the problems are. Formatting, syntax repairs and behaviour
          changes are reviewed separately, and nothing is written until you ask.
